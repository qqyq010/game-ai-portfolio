# 검수 요청문

아래 항목에 자기 작업의 내용을 넣어 AI에 전달합니다. 예를 들어 문서 개편이면 기존 링크와 변경 파일 목록을, 게임 버그 수정이면 재현 순서와 빌드·플레이 결과를 넣습니다.

```text
처음 요청
[사용자가 원한 결과와 완료 조건]

수정 범위
[변경 가능한 문서·코드·데이터와 보호해야 하는 부분]

실제 변경
[시작점, 변경 파일 목록이나 비교 내용]

확인 자료
[실행한 명령과 결과, 스크린샷, 수동 플레이 기록]
[이미 공유된 링크나 같이 확인해야 하는 화면]

먼저 실제 변경을 읽어 줘.
요구별로 반영 여부와 근거가 있는 파일·행·검사 결과를 적어 줘.
범위 밖 변경이 있으면 위치와 영향을 써 줘.
실행한 검사와 실행하지 못한 검사를 따로 표시해 줘.
내가 고칠 항목을 정하면 같은 조건으로 다시 확인할 수 있게 적어 줘.
```

근거가 없는 칸은 확인이 필요한 상태로 남깁니다. 수정한 뒤에는 처음 요청과 같은 검사 조건을 다시 사용합니다. [이번 포트폴리오에 적용한 예시](review-example.md)
