# 검수 요청문

아래 항목에 자기 작업 내용을 채워 AI에 전달합니다. 문서를 고쳤다면 기존 주소와 변경 파일 목록을 넣습니다. 게임 버그를 고쳤다면 문제가 난 순서부터 적고 빌드 결과와 직접 플레이한 기록을 붙입니다.

```text
처음 요청
[원한 결과와 완료 조건]

수정 범위
[고쳐도 되는 부분과 손대면 안 되는 파일이나 데이터]

실제 변경
[비교할 수정 전 상태와 바뀐 파일 목록 또는 전후 차이]

확인 자료
[실행한 검사와 결과. 필요하면 화면과 수동 플레이 기록 첨부]
[이미 공유한 링크나 함께 확인할 화면]

먼저 실제로 바뀐 내용을 읽어 줘.
요구 하나마다 반영됐는지 확인하고 파일의 어느 부분이나 어떤 검사 결과를 봤는지 적어 줘.
범위 밖에서 바뀐 곳이 있으면 어느 파일에서 무엇이 달라졌는지 적어 줘.
실행한 검사와 해 보지 못한 검사를 나눠 적어 줘.
수정한 뒤 같은 방법으로 다시 확인할 수 있게 어떻게 검사했는지도 남겨 줘.
```

근거가 없으면 추가 확인이 필요하다고 적습니다. 수정 뒤에는 같은 조건으로 다시 검사합니다. [이 포트폴리오에 적용한 예시](review-example.md)
