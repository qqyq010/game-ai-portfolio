# quality-pass · 수정이 끝났다는 말의 근거 확인하기

AI가 작업을 마쳤다고 하면 처음 요청했던 것과 실제로 바뀐 것을 다시 맞춰 봅니다. 이 순서를 반복해서 설명할 일이 많아서 제가 만든 Codex 검수 지침에 담았습니다.

## 네 단계로 적용하기

1. **비교할 기준을 정합니다.** 처음 요청, 완료 조건, 바꿔도 되는 범위, 함께 열어야 할 자료를 한곳에 적습니다.
2. **실제 변경을 붙입니다.** 변경 파일이나 비교 내용을 주고, 실행한 검사 결과를 붙입니다. Unity 작업이면 빌드 로그와 직접 플레이 기록을 각각 넣습니다.
3. **요구별 근거를 받습니다.** 어느 파일이나 검사 결과에서 확인했는지, 범위 밖에 바뀐 내용이 있는지, 실행하지 못한 검사가 무엇인지 묻습니다.
4. **필요한 것을 고치고 다시 봅니다.** 제가 고칠 사항을 정한 뒤 같은 조건으로 재검사합니다.
