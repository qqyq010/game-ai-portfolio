# Git 개편에 적용한 검수 예시

기존 저장소를 기준으로 바뀐 문서를 다시 읽었습니다. 처음 요청은 첫 화면에서 출시작과 시연을 찾기 쉽게 만들고, 각 작품에서 당시 확인한 근거까지 이어지는 Git을 만드는 것이었습니다. 함께 본 것은 기존 README, 개편 후 파일과 변경 목록, 이미 공유된 문서 주소, 시연과 PDF입니다.

## 실제로 확인하고 고친 것

### 첫 화면에서 필요한 자료 열기

기준 커밋의 README에는 출시 페이지, 공식 영상, PDF, quality-pass 중 PDF만 직접 연결돼 있었습니다. 네 링크를 README에 뒀습니다. 공식 영상 주소는 Steam 페이지 안의 영상 구역까지 확인해 수정했습니다.

### 먼저 공유된 사례에서 이어 읽기

기존 Coin Survivor 문서에는 무기 판매와 초반 골드 소제목이 있었습니다. 두 소제목으로 접근할 수 있게 두고 새 판매 확인표와 밸런스 사례로 연결했습니다. 옛 골드 주소에서 출발해 새 페이지까지 이동하는 것을 미리보기에서 확인했습니다.

### 서로 다른 플레이 기록을 알아보기

이전 PDF와 게임 기록에서 각기 다른 수치를 확인했습니다. 10월 보유 수, 11월 지원 당시 라이브러리 수, 9월 시간 표시 항목에 시점과 기준을 붙였습니다. 당시 시간 목록 162행도 대조했습니다.

### 휴대전화 폭에서 문장이 끊기는 위치 확인하기

390px 미리보기에서 제목의 마지막 글자와 PDF 링크가 다음 줄로 밀렸습니다. 이 예시도 표에서 한 줄이 지나치게 짧게 끊겼습니다. 첫 화면의 제목과 링크를 줄이고 이 예시는 소제목과 문단으로 바꿨습니다. 변경 검사에서 잡힌 줄 끝 공백도 고친 뒤 같은 조건으로 다시 확인했습니다.

## 같은 조건으로 확인하기

1. 저장소 첫 화면에서 **STOVE**, **공식 영상**, **PDF** 위치를 확인합니다. AI 협업 항목에서 검수 지침과 이 예시로 들어갈 수 있는지도 봅니다.
2. [예전 골드 사례 주소](../../cases/coin-survivor.md#초반-골드로-어떤-선택이-가능한가)를 열고 새 사례로 넘어가는지 확인합니다. PDF와 화면 자료도 열어 봅니다.
3. Git에서 개편 범위와 공백 오류를 확인합니다.

```text
git diff --name-status 72fa808
git diff --check 72fa808
```

이 예시의 결과는 로컬 Git 개편과 문서 미리보기 기준입니다. 게임별 실행 결과는 각 프로젝트에 적힌 당시 기록을 따릅니다.
