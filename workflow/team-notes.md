# 회의 초안에서 팀의 할 일로

Coin Survivor 회의 영상은 faster-whisper로 전사하고 회의록 초안을 만들었습니다. 전사본에 빠진 내용은 제 메모와 대조했습니다. 4월 27일에는 아이템을 끌어 놓는 조작에서 집었다 놓는 조작으로 바꾸자는 제 안건을 추가해 팀과 공유했고, 다음 작업을 정하는 데 활용했습니다.

| 구간 | 제가 한 일 | AI·도구에 맡긴 일 |
| --- | --- | --- |
| 회의 뒤 | 결정 사항과 다음 작업이 실제 논의와 맞는지 확인 | 음성 전사, 회의록 초안 정리 |
| 누락 발견 뒤 | 인벤토리 조작 변경 안건을 메모에서 복원 | 빠진 내용을 반영해 문서 정리 |
| 작업 중 | Obsidian에서 완료 항목과 남은 일, 이전 문제 확인 | Coin Survivor·Fisher 작업 기록 정리, 찾기 어려운 이름 개선 |

전사 정확도와 시간 절감은 계량하지 않았습니다. 공유용 회의록으로 보완한 사례이며 원본 대화와 팀 작업 기록은 싣지 않았습니다.
