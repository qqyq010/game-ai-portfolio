# 찾은 자료가 지금 작업에 맞는지 확인하기

지금 할 일을 찾으려고 검색했는데 예전 설계 문서가 먼저 나왔습니다. 새 검색 방식이 지금 필요한 문서를 더 잘 찾는지부터 봤습니다. 관련 없는 결과가 늘어나는지도 기준으로 삼았습니다. 비교와 코드 변경은 AI에 맡기고 어떤 변경을 쓸지는 결과를 보고 정했습니다.

| 해 본 일 | 확인한 방법 | 결과 |
| --- | --- | --- |
| 지금 작업 안내를 찾기 어려웠음 | 검색에 쓰는 별칭 두 개를 안내에 추가 | 같은 검사 65개 중 통과 건수가 64개에서 65개로 늘어남 |
| Kiwi로 검색 보완 | 빠지던 문서를 찾는지와 잘못 걸리는 문서가 늘어나는지 비교 | 찾지 못한 문서는 그대로였고 관련 없는 결과가 생겨 적용을 보류 |
| MiniLM으로 유사한 문서 찾기 | 데이터를 준비해 로컬에서 실행을 시도 | 메모리 때문에 중단. 검색 효과는 확인하지 못함 |
| 이미지에서 글자 읽기 | 작은 예시를 준비 | 글자를 얼마나 더 잘 읽는지는 확인이 필요함 |

같은 검사에서 별칭을 추가한 뒤 결과가 나아진 것은 한 건이었습니다. 지금 할 일과 승인 여부는 검색에 나온 문서를 직접 열어 날짜와 현재 작업 기록을 확인합니다.
