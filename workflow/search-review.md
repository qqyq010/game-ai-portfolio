# 찾은 자료가 지금 작업에 맞는지 확인하기

다음 할 일을 검색했는데 예전에 써 둔 설계가 먼저 나왔습니다. 실제 업무에서 필요한 자료를 더 잘 찾는지, 관련 없는 결과가 더 늘어나지 않는지부터 보기로 했습니다. 비교와 코드 변경은 AI에 맡기고, 결과를 보고 적용할 범위를 정했습니다.

| 상황 | 어떻게 비교했나 | 확인 결과 |
| --- | --- | --- |
| 현재 작업 안내가 검색에 빠짐 | 현재 안내에 검색 별칭 두 개를 추가 | 고정 검사 65개에서 64개 통과가 65개 통과로 바뀜 |
| Kiwi 보완 검토 | 놓치던 자료를 찾는지와 오탐을 비교 | 누락은 그대로였고 오탐이 생겨 적용을 보류 |
| MiniLM 유사도 검토 | 데이터를 준비해 로컬 환경에서 시도 | 메모리 조건 때문에 중단. 효과 미확인 |
| 이미지 글자 인식 검토 | 최소 예시를 준비 | 실제 인식 개선은 추가 확인 대상 |

고정 검사에서 달라진 결과는 한 항목입니다. 지금 할 일이나 승인 상태는 검색 결과가 보여 주는 문서의 날짜와 현재 작업 기록을 열어 봅니다. [평소 Codex 작업 방식](codex.md)
