# 게임 제작과 AI 협업

게임을 하다 선택이 막히는 순간을 살펴봅니다. Unity 팀 프로젝트에서는 상점과 인벤토리를 맡았고 개인 잠입 퍼즐에서는 실패 뒤 다시 시작하는 흐름을 만들었습니다.

## 제작에 참여한 게임

- **[Coin Survivor](projects/coin-survivor/README.md)** · 팀 제작·출시. 상점과 인벤토리, 초반 밸런스를 다뤘습니다.
- **[EscapeRoom](projects/escape-room/README.md)** · 개인 잠입 퍼즐. 적의 감지와 실패 후 복구를 구현했습니다. [5초 감지·복귀 시연](projects/escape-room/media/enemy-detection.gif)
- **[Fisher Idle RPG](projects/fisher-idle-rpg/README.md)** · 팀 제작. 상점·요리·가방·도감 화면을 게임 데이터와 연결했습니다.
