# 게임 제작과 AI 협업

Coin Survivor에서 상점과 인벤토리를 맡았습니다. 직접 플레이하면서 골드를 어디에 쓰느냐에 따라 다음 전투가 어떻게 달라지는지 살폈습니다. 혼자 만든 EscapeRoom에서는 실패한 이유에 따라 다시 시작하는 위치를 달리했습니다.

## 제작에 참여한 게임

- [**Coin Survivor**](projects/coin-survivor/README.md)는 팀으로 만들어 출시했습니다. 상점과 인벤토리를 맡았고 초반 밸런스를 조정하는 데도 참여했습니다.
- [**EscapeRoom**](projects/escape-room/README.md)은 혼자 만든 잠입 퍼즐입니다. 적의 시야를 피해 퍼즐을 풉니다. [적에게 들킨 뒤 돌아오는 장면(5초)](projects/escape-room/media/enemy-detection.gif)
- [**Fisher Idle RPG**](projects/fisher-idle-rpg/README.md)는 팀으로 만든 방치형 RPG입니다. 상점과 요리 화면을 비롯해 가방과 도감도 게임 데이터와 연결했습니다.
