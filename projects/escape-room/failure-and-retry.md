# 실패한 뒤 어디에서 다시 움직일까

적에게 들키거나 퍼즐을 틀려도 금방 다시 해 볼 수 있게 만들고 싶었습니다. 그래서 어디서 다시 움직일지와 이미 푼 퍼즐을 어떻게 남길지 따로 생각했습니다.

적과 플레이어 사이의 거리와 적이 바라보는 방향으로 시야에 들어왔는지 확인합니다. 시야 안이라면 중간에 가리는 물체가 있는지 봅니다. 실패했을 때는 조작을 멈추고 원인에 따라 어디로 돌아갈지 정한 뒤 다시 움직일 수 있게 합니다.

## 적에게 들켰을 때와 퍼즐을 틀렸을 때

| 시작 씬에서 실패한 이유 | 다시 움직이기까지 |
| --- | --- |
| 적에게 들킴 | 0.5초 뒤 체크포인트로 돌아가 다시 조작할 수 있음 |
| 일반 퍼즐을 틀림 | 0.2초 뒤 그 자리에서 다시 조작할 수 있음 |
| 보물 구간에서 실패함 | 0.5초 뒤 체크포인트로 돌아가 다시 조작할 수 있음 |

3월 백업의 `SceneA` 설정과 코드에서 위 차이를 확인했습니다. 퍼즐을 한 번 틀릴 때마다 같은 길을 걸어오면 다시 도전하기까지 시간이 걸립니다. 적에게 들키거나 보물 구간에서 실패하면 체크포인트로 돌아가게 했고 일반 퍼즐은 그 자리에서 다시 시도할 수 있게 했습니다.

시연 뒤에는 일부 구간이 어렵고 어디에서 적에게 들키는지나 특수능력이 작동했는지 알아차리기 힘들다는 의견이 있었습니다. 다음에 확인한다면 화면을 보면서 언제 들켰다고 느꼈는지와 다시 움직일 수 있다는 걸 언제 알아차렸는지 물어보고 싶습니다.
