# 시작 씬과 실패 후 복구 자동 검사

2026년 8월 24일 EscapeRoom 소스를 임시로 복사해 Unity Test Runner로 검사한 기록입니다. 검사 1건이 통과했고 실행은 종료 코드 0으로 끝났습니다.

1. `SceneA`를 열고 씬과 주요 오브젝트가 초기화되는지 봤습니다.
2. 120프레임 동안 실행했습니다.
3. 입력을 잠그면 `Locked`가 되고 잠금을 풀면 `Normal`로 돌아오는지 봤습니다.
4. 대표 퍼즐을 틀렸을 때도 입력 잠금이 풀리고 `Normal`로 돌아오는지 확인했습니다.

적의 시야가 끝나는 경계에서 감지가 제대로 되는지와 다른 퍼즐을 여러 번 다시 풀 수 있는지는 추가로 살펴야 합니다. 전체를 수동으로 끝까지 플레이하거나 배포 빌드에서 실행한 결과도 이 검사에는 포함돼 있지 않습니다.
