# 시작 씬과 실패 후 복구 자동 검사

2026년 8월 24일 EscapeRoom 소스의 임시 복사본에서 Unity Test Runner를 실행했습니다. 기록에 남은 결과는 **종료 코드 0, 검사 1건 통과**입니다.

1. `SceneA`를 열어 씬과 주요 오브젝트가 초기화되는지 확인했습니다.
2. 120프레임을 연속으로 실행했습니다.
3. 입력을 잠그면 `Locked`가 되고 풀면 `Normal`로 돌아오는지 확인했습니다.
4. 대표 퍼즐에서 실패를 처리한 뒤 입력 잠금이 남아 있지 않고 `Normal`로 복구되는지 확인했습니다.

추가로 확인할 범위는 감지 시야각의 경계, 다른 퍼즐의 반복 시도, 전체 수동 완주와 배포 빌드입니다. 위 결과는 임시 복사본의 시작 씬과 대표 복구 경로를 보여 줍니다.
