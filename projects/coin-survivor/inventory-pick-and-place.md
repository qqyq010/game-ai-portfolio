# 아이템을 내려놓을 수 없을 때

상점과 인벤토리에는 아이템 합성도 넣을 예정이었습니다. 클릭해서 아이템을 집거나 놓는 동작부터 제대로 되어야 합성 조건을 확인할 수 있다고 봤습니다. 우선 상점과 인벤토리 안에서 클릭 조작을 손보고 합성은 다음으로 미뤘습니다.

## 완료 보고를 받고 다시 확인한 부분

Obsidian에서 Markdown으로 적은 계획을 읽고 손볼 곳을 정했습니다. Codex가 구현하는 중에 팀원이 맡은 전투 파일도 변경 목록에 들어왔습니다. 바뀐 곳을 확인하고 원래 계획한 범위에 맞춰 달라고 했습니다.

클릭 조작을 마쳤다는 답을 받았을 때는 제 화면의 코드와 설명이 달라 보였습니다. 아이템의 어느 부분을 클릭했는지와 가방 밖을 클릭하면 어떻게 되는지를 나눠 물었습니다. 판매 확인창이 뜨는 조건도 현재 파일에서 다시 찾아 달라고 했습니다. 그때 비교한 첨부 화면이 어느 버전이었는지는 기록으로 확인하기 어렵습니다.

## 제가 확인한 동작

| 상황 | 당시 Play Mode 기록 |
| --- | --- |
| 3×3 아이템의 중앙과 가장자리를 각각 집음 | 두 경우 모두 아이템 중심이 마우스를 따라감 |
| 1×3 무기를 집거나 다른 아이템 하나 위에 놓음 | 무기 중심이 마우스를 따라감. 하나와 겹치면 자리를 바꾸고 그 아이템을 집음 |
| 여러 아이템과 겹쳐 놓을 곳이 없음 | 들고 있던 아이템이 제자리로 돌아감 |
| 아이템을 들고 상점을 클릭함 | 판매 확인창이 뜨고 구매는 일어나지 않음. 판매를 취소하면 아이템이 제자리로 돌아감 |
| 아이템을 들고 있지 않은 상태에서 구매함 | 평소대로 상점에서 구매할 수 있음 |

이 동작들을 먼저 확인해 두면 합성을 넣은 뒤 문제가 생겼을 때 클릭 조작부터 다시 봐야 하는지 합성 조건을 봐야 하는지 판단하기 쉽습니다.
