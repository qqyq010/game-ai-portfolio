# 아이템을 내려놓을 수 없을 때

상점과 인벤토리에는 합성도 들어갈 예정이었습니다. 먼저 아이템을 클릭해 들고 내려놓는 동작이 안정되어야 합성 조건도 제대로 볼 수 있다고 판단했습니다. 그래서 합성은 뒤로 미루고 상점과 인벤토리 안에서만 조작을 손보는 계획을 정했습니다.

## 제가 정한 확인 조건

Obsidian에서 Markdown 계획을 읽으며 수정 범위를 좁혔습니다. Codex는 그 범위에서 코드를 조사하고 구현했습니다. 저는 변경 내역을 보고 팀원이 맡은 전투 쪽에 들어간 변경을 다시 확인하도록 요청한 뒤, Unity에서 아래 동작을 살폈습니다.

| 상황 | 확인하려던 동작 |
| --- | --- |
| 모양이 다른 아이템을 집음 | 잡는 위치에 따라 아이템이 바로 엉뚱한 칸으로 튀지 않는지 |
| 이미 놓인 아이템 하나와 겹침 | 교환할 수 있는 경우에만 자리를 바꾸는지 |
| 여러 아이템과 겹쳐 놓을 곳이 없음 | 들고 있던 아이템이 제자리로 돌아가는지 |
| 아이템을 들고 상점에서 구매를 누름 | 자리 배치가 끝날 때까지 추가 구매가 막히는지 |

당시 제 Play Mode 기록에 위 조건들이 남아 있습니다. 특히 여러 아이템에 겹치면 그대로 두는 대신 원래 칸으로 돌아오는지 직접 확인했습니다. 서로 다른 조작을 한꺼번에 넣으면 어디서 어긋났는지 찾기 어려워서, 들어 올리기와 내려놓기를 먼저 확인할 수 있게 범위를 정한 작업입니다.
