# 2레벨 무기를 팔면 1레벨은 남아야 한다

2레벨 무기를 팔았더니 가방에서는 사라졌는데 전투에서는 계속 공격했습니다. 같은 종류의 1레벨 무기도 장착돼 있었습니다. 그래서 2레벨은 공격을 멈추고 1레벨은 계속 공격하는지 두 가지를 확인했습니다.

| 담당 | 작업 |
| --- | --- |
| 본인 | 문제가 나는 순서를 설명하고 수정 범위를 인벤토리로 정했습니다. 수정 뒤 Play Mode로 확인하고 결과를 기록했습니다. |
| Codex | 인벤토리에서 판매 이벤트를 처리하는 코드를 수정하고 빌드했습니다. |
| 팀원 | 판매 이벤트를 받아 전투 상태에 반영하는 Player 쪽 코드를 구현했습니다. |

## 2026년 5월 12일 Unity Play Mode 기록

1. 같은 종류의 무기를 1레벨과 2레벨로 각각 준비합니다.
2. 2레벨 무기를 판매합니다.
3. 전투에서 판매한 2레벨만 빠지고 1레벨은 남았는지 확인합니다.

| 함께 확인한 상황 | 당시 결과 |
| --- | --- |
| 2레벨 판매 직후 전투 | 2레벨만 빠지고 1레벨은 계속 공격함 |
| 판매 확정과 취소 | 두 동작 모두 정상 |
| 빈칸이 있는 가방에서 1레벨 구매 | 구매한 무기가 장착됨 |
| 가득 찬 가방에서 같은 1레벨 구매 | 2레벨로 바뀜 |
| 같은 무기가 가방에 여럿 있을 때 구매 | 한 개만 합성되고 나머지는 그대로 남음 |
| 무기를 직접 합성함 | 정상으로 기록 |
| 패시브 아이템을 사거나 팔거나 합성함 | 정상으로 기록 |
| 방어구 구매와 판매 | 당시 시험할 아이템을 구하지 못함 |

빌드 결과는 Codex 작업 기록에 있습니다. 위 표는 그날 제가 Unity에서 직접 시험하면서 적은 결과입니다.
