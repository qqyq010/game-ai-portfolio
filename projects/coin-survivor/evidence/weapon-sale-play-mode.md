# 2레벨 무기를 팔면 1레벨은 남아야 한다

2레벨 무기를 팔았더니 가방에서는 사라졌는데 전투에서는 계속 공격했습니다. 같은 종류의 1레벨 무기도 장착돼 있어서, 판매한 무기만 제거되는지와 남겨야 할 무기가 계속 공격하는지를 따로 봤습니다.

| 담당 | 작업 |
| --- | --- |
| 본인 | 재현 상황을 설명하고 수정 범위를 인벤토리로 정했습니다. 수정 후 작성한 Play Mode 기록으로 결과를 확인했습니다. |
| Codex | 인벤토리 쪽의 판매 이벤트 처리를 수정하고 빌드했습니다. |
| 팀원 | 그 이벤트를 받아 전투 상태에 반영하는 Player 쪽 코드를 구현했습니다. |

## 2026년 5월 12일 Unity Play Mode 기록

1. 같은 종류의 무기를 1레벨과 2레벨로 각각 준비합니다.
2. 2레벨 무기를 판매합니다.
3. 판매한 2레벨만 전투에서 빠지고 1레벨은 남았는지 확인합니다.

| 함께 본 조건 | 당시 기록 |
| --- | --- |
| 판매한 2레벨과 남겨야 할 1레벨 | 2레벨 제거, 1레벨 전투 유지 |
| 판매 확정과 취소 | 정상 동작 |
| 빈칸이 있는 가방에서 1레벨 구매 | 장착 확인 |
| 가득 찬 가방에서 같은 1레벨 구매 | 2레벨로 교체 확인 |
| 같은 무기가 가방에 여럿 있을 때 구매 | 한 개만 합성되고 나머지 유지 |
| 수동 무기 합성과 패시브의 구매·판매·합성 | 정상으로 기록 |
| 방어구 구매·판매 | 당시 재현할 아이템을 구하지 못해 미확인 |

빌드는 Codex의 작업 결과에, 플레이 동작은 당시 제 확인 기록에 남았습니다. 독립 녹화와 원본 콘솔 출력은 이 사례의 추가 확인 자료입니다.
