# ESC를 한 번 눌렀는데 상점까지 닫혔다

상점이나 인벤토리 위에 가이드가 떠 있는 동안 ESC를 누르면 두 창이 같은 순간에 닫히는 일이 있었습니다. 안내를 닫고 이어서 물건을 보려던 사람에게는 진행 중이던 화면까지 사라지는 문제입니다.

## 무엇을 한 번씩 확인할까

| 입력 전 상태 | 한 번 누른 뒤 기대 동작 |
| --- | --- |
| 상점 위에 안내가 열려 있음 | 안내가 닫히고 상점은 열려 있음 |
| 인벤토리 위에 안내가 열려 있음 | 안내가 닫히고 인벤토리는 열려 있음 |
| 안내를 닫은 상태에서 한 번 더 누름 | 현재 열려 있는 상점이나 인벤토리가 닫힘 |

5월 19일 작업에는 가이드가 따로 ESC를 받던 경로를 정리하고, 위에 겹친 창부터 닫게 한 변경이 남아 있습니다. 따라서 한 번의 입력이 두 창으로 전달되는 조건을 기준으로 보면 됩니다. 당시 가이드·거래 UI 변경 묶음은 사용자의 Play Mode 통과 기록이 있고, 위 조합마다 따로 기록된 실행 결과는 추가 확인이 필요합니다.
