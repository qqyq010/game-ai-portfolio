# ESC를 한 번 눌렀는데 상점까지 닫혔다

상점이나 인벤토리 위에 안내가 떠 있을 때 ESC를 누르면 안내와 그 아래 창이 함께 닫혔습니다. 안내만 닫고 물건을 계속 보려던 플레이어는 상점을 다시 열어야 했습니다.

## ESC를 눌렀을 때 닫혀야 하는 창

| 누르기 전 | 한 번 누른 뒤 기대하는 동작 |
| --- | --- |
| 상점 위에 안내가 열려 있음 | 안내가 닫히고 상점은 그대로 열려 있음 |
| 인벤토리 위에 안내가 열려 있음 | 안내가 닫히고 인벤토리는 그대로 열려 있음 |
| 안내를 닫은 상태에서 한 번 더 누름 | 열려 있는 상점이나 인벤토리가 닫힘 |

5월 19일 작업 기록에는 안내가 별도로 ESC를 받던 코드를 정리하고 가장 위에 뜬 창부터 닫도록 바꾼 내용이 있습니다. 안내와 거래 화면을 묶어 Play Mode에서 확인한 기록은 있습니다. 표의 세 상황을 하나씩 실행한 결과는 따로 남아 있지 않습니다.
