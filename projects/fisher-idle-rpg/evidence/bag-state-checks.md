# 씬 전환 뒤 가방 상태 확인 기록

2026년 6월 팀 작업 기록입니다. 메인 화면과 저장 데이터는 유지되는데 가방에만 초기값이 보이는 문제를 살핀 뒤 두 경우를 각각 실행했습니다.

| 실행한 상황 | 당시 확인한 결과 |
| --- | --- |
| 멀티플레이 씬을 다녀온 뒤 | 대기 중인 요청이 없었습니다. 저장 데이터와 클라이언트 상태가 일치했고 가방에 보이는 아이템 수량과 재화도 같았습니다. 이전에 보이던 초기값도 사라졌습니다. |
| 씬을 바꾸기 전에 대기 작업이 남아 있을 때 | 남은 작업을 반영해 처리 목록을 비웠습니다. 그다음 데이터를 미리 불러오고 씬을 바꾸는 순서를 확인했습니다. |

위 두 결과는 서로 다른 실행에서 나왔습니다. 대기 작업이 있는 상태로 시작해 씬을 다녀온 뒤 가방의 최종 값까지 한 번에 확인한 기록은 없습니다.
