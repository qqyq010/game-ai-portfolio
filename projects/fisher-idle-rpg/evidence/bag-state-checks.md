# 씬 전환 뒤 가방 상태 확인 기록

2026년 6월 팀 작업의 확인 기록을 기준으로 정리했습니다. 메인 화면과 저장 데이터가 유지되는 동안 가방에만 초기 상태처럼 보이는 값이 나오는지 살폈습니다.

| 확인한 상황 | 당시 실행에서 본 것 |
| --- | --- |
| 멀티플레이 씬을 왕복한 뒤 안정된 상태 | 대기 큐가 비었고 저장 데이터, 클라이언트 상태, 가방의 아이템·재화 표시가 일치했습니다. 이전에 나타났던 초기 상태 표시도 보이지 않았습니다. |
| 씬 전환 전에 대기 작업이 있던 상태 | 대기 작업을 반영하고 큐를 비운 다음, 데이터를 미리 불러오고 씬을 전환하는 순서를 확인했습니다. |

두 조건은 별도 실행에서 확인했습니다. 대기 작업이 있는 채로 시작해 같은 실행에서 최종 일치까지 한 번에 추적하는 검사는 남아 있습니다.
