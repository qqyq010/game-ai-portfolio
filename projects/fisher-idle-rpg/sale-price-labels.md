# 가방의 개당 가격과 총 판매가를 나누기

가방에서 아이템을 볼 때와 여러 개를 판매할 때는 알고 싶은 금액이 다릅니다. 상세 화면에서는 하나의 가격을 보고, 확인창에서는 지금 선택한 수량을 팔았을 때 받는 돈을 봅니다. 두 화면에서 비슷한 ‘예상 판매’ 표현을 쓰면 수량이 바뀌었을 때 같은 금액으로 읽힐 수 있었습니다.

- **아이템 상세**에는 ‘개당’을 표시했습니다. 목록을 넘겨 볼 때 한 개의 가격을 읽을 수 있습니다.
- **판매 확인과 완료 알림**에는 ‘총 판매가’를 표시했습니다. 선택한 수량을 기준으로 확인하는 금액입니다.
