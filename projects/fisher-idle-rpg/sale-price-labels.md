# 가방에서 한 개 가격과 총 판매가를 구분하기

가방에서 아이템을 살펴볼 때는 한 개가 얼마인지 궁금합니다. 여러 개를 팔 때는 이번 판매에서 얼마를 받는지가 중요합니다. 두 화면 모두 ‘예상 판매’라고 쓰면 수량을 바꿨을 때 어느 금액을 보여 주는지 헷갈릴 수 있었습니다.

- **아이템 상세**에는 ‘개당’을 붙였습니다. 목록에서 물건을 고를 때 한 개의 가격을 볼 수 있습니다.
- **판매 확인창과 완료 알림**에는 ‘총 판매가’를 표시했습니다. 선택한 수량을 팔았을 때 받는 금액입니다.
