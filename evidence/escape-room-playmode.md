# EscapeRoom 자동 Play Mode 검사 범위

2026년 8월 24일 현재 소스의 임시 복사본을 사용한 자동 검사 기록입니다. Unity Test Runner 종료 코드 0, 검사 1건 통과가 보존돼 있습니다.

1. SceneA를 열어 씬과 주요 오브젝트가 초기화되는지 확인했습니다.
2. 120프레임 연속 실행을 확인했습니다.
3. 입력 잠금 후 Locked 상태가 되고, 해제하면 Normal 상태로 돌아오는지 확인했습니다.
4. 대표 퍼즐 실패 처리 뒤 남은 입력 잠금이 없고 Normal 상태로 복구되는지 확인했습니다.

감지 시야각의 모든 경계, 다른 퍼즐의 반복 시도, 사람이 직접 모든 퍼즐을 완주하는 과정, 배포용 실행 파일의 동작은 검사 범위 밖입니다. [프로젝트 소개](../cases/escape-room.md)
