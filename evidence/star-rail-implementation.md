# Star Rail Lab 입력과 결과 처리

[코드 발췌](../artifacts/star-rail/rotation-input-excerpt.jsx)는 2026년 10월 공개 스냅샷에서 가져왔습니다. 작성은 Codex가 맡았고, 저는 보유 장비와 콘텐츠 조건을 어떻게 반영할지 정리하고 결과를 확인했습니다. 발췌 파일은 관련 처리를 읽어보기 위한 것으로 프로젝트 전체 실행에는 별도 구성 요소가 필요합니다.

- 입력이 바뀌면 표시 중인 결과를 비웁니다.
- 이전 입력의 응답이 늦게 도착해도 현재 결과를 덮어쓰지 않도록 구분합니다.
- 계산 자료의 식별값을 비교합니다.

검사 문서에는 전투 길이 변경 후 재계산과 지원하지 않는 파티로 바꿨을 때 이전 결과를 재사용하지 않는 사례가 남아 있습니다. 실행 원문 로그는 확보하지 못했습니다. [프로젝트 사례](../cases/star-rail-lab.md)
