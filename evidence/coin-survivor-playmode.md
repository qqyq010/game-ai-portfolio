# Coin Survivor 무기 판매 수정 뒤 Play Mode 확인

2026년 5월 12일 당시 개인 작업 기록에서 확인한 항목입니다. 제가 Unity 에디터에서 확인한 결과를 바탕으로 작성했습니다.

| 구분 | 확인 조건 | 당시 기록 |
| --- | --- | --- |
| 오류 재현에 대한 확인 | 동일 종류 1레벨·2레벨 무기 중 2레벨 판매 | 2레벨만 전투에서 제거되고 1레벨 유지 |
| 판매 동작 확인 | 판매 확정과 취소 | 정상으로 기록 |
| 다른 거래 경로 확인 | 빈칸이 있는 가방에서 1레벨 구매 | 무기 장착 확인 |
| 가득 찬 가방 | 같은 1레벨 구매로 합성 | 2레벨 교체 확인 |
| 같은 무기가 중복된 가방 | 구매로 자동 합성 | 한 개만 2레벨로 바뀌고 나머지 유지 |
| 다른 합성·아이템 경로 | 수동 무기 합성과 패시브 구매·판매·합성 | 정상으로 기록 |
| 확인하지 못한 범위 | 방어구 구매·판매 | 당시 재현할 아이템이 없어 확인 못함 |

Codex 코드 수정 및 빌드 기록은 [수정 사례](../cases/coin-survivor.md)에 역할과 함께 정리했습니다. 이 표의 결과는 독립 녹화나 원본 콘솔 출력이 아닌 당시 Play Mode 기록에 근거합니다.
