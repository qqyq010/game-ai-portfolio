# 와우 포에버에서 다음에 갈 곳을 정리한 방법

스카이본 드루이드를 키우면서 지금 레벨에 어디를 가야 하는지와 어떤 직업 퀘스트부터 해야 하는지가 궁금했습니다. 저는 필드 퀘스트를 하다가 레벨이 부족할 때 던전을 돌려고 했습니다. 처음부터 던전을 반복하는 경로로는 제가 하려던 플레이를 계획하기 어려웠습니다.

AI에는 필드 퀘스트를 중심에 두고 지도에서 레벨에 맞는 지역과 필수 직업 퀘스트를 바로 찾을 수 있게 해 달라고 했습니다. 던전은 선택할 수 있게 따로 넣었습니다. 첫 지도에 클래식 퀘스트 경로가 섞여 있어 포에버에서도 같은 순서로 진행할 수 있는지 다시 살폈습니다. 실제 위치를 확인하기 어려운 퀘스트는 추정해서 찍은 표시를 빼 달라고 했습니다.

| 안내에 넣은 내용 | 플레이할 때 확인할 것 |
| --- | --- |
| 레벨대별 퀘스트 지도 | 지금 레벨에서 갈 수 있는 지역과 들를 순서 |
| 필수 직업 퀘스트 | 퀘스트를 받았는지와 해당 기술을 실제로 배웠는지 |
| 선택 던전과 퀘스트 | 입장하기 전에 열어야 할 지역과 먼저 해야 할 퀘스트 |

Codex가 만든 HTML과 당시 기록에서 위 세 항목의 구성을 확인했습니다. 지도에는 이동 시간과 경험치 효율을 재지 않았다고 적혀 있습니다. 어느 길이 더 빠른지 알려면 포에버에서 같은 조건으로 직접 돌아보고 걸린 시간을 비교해야 합니다.
