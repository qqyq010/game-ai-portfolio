# 와우 포에버에서 다음에 갈 곳을 정리한 방법

스카이본 드루이드를 키울 때 레벨대마다 어디로 가야 할지에 더해, 어떤 직업 퀘스트를 먼저 챙겨야 하는지가 궁금했습니다. 던전을 계속 반복하는 경로를 전제로 하면 실제로 하려던 플레이와 맞지 않았습니다.

그래서 AI에 필드 퀘스트를 기본으로 두고, 레벨대별 지역·직업 해금·선택할 수 있는 던전을 따로 볼 수 있는 지도를 요청했습니다. 처음 나온 안에는 클래식 동선이 섞여 있었습니다. 포에버에서 같은 퀘스트가 실제로 이어지는지 다시 물었고, 확인이 어려운 위치는 지도에서 추정 핀을 덜어내도록 했습니다.

| 안내에 들어간 것 | 플레이할 때 보려던 기준 |
| --- | --- |
| 레벨대별 퀘스트 지도 | 현재 레벨에서 들를 지역과 방문 순서 |
| 필수 직업 퀘스트 | 수락 여부와 함께 해당 기술을 실제로 배웠는지 |
| 선택 던전과 퀘스트 | 입장 전에 지역과 선행 퀘스트를 챙길 수 있는지 |

Codex가 만든 HTML 파일에 세 항목과 ‘동선·경험치 효율 미실측’ 안내가 있습니다. 확인한 범위는 남아 있는 HTML과 당시 작업 기록입니다. 포에버 전용 최단 거리·완주 효율을 확인하려면 같은 조건에서 실제 진행 시간을 따로 재야 합니다.
