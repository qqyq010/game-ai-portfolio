# FM27에서 읽히지 않은 예산으로 거래를 정하지 않기

렉섬을 운영할 때 이번 시즌은 현재 선수단으로 보내고 승격 후 개편하려 했습니다. 대체 선수를 구하기 어렵다면 다음 시즌 기준 24세 이하 선수는 남기기로 했습니다. 그래서 선수 목록을 볼 때도 계약과 급료를 확인할 수 있는지, 실제로 이적에 쓸 수 있는 예산은 얼마인지가 중요했습니다.

## 실제 실행과 수정 후보에서 본 결과

**0.2.1 실제 실행**에서는 구단 이름과 선수 목록의 응답이 있었습니다. 감독·팀과 선수의 상세 ID가 확인되지 않아 도구는 수집 결과를 사용하지 않았습니다. 이름과 목록을 찾았다는 결과만으로 계약이나 이적 예산이 읽혔다고 볼 수 없었습니다.

**0.2.2 수정 후보**에서는 응답을 구분하는 조건을 바꾸고 오프라인에서 빌드와 검사를 했습니다. C# 계약 검사 36개와 Python 검사 17개가 통과했습니다. 이 후보의 실제 게임 판독과 화면 값 대조는 남은 확인 항목입니다.

제가 정한 목표는 당장 쓸 선수단과 승격 뒤에 바꿀 선수단을 나누는 것이었습니다. 예산과 급료가 확인되기 전에는 필요한 포지션까지만 좁히고, 특정 거래에 쓸 돈은 확인한 뒤 판단할 수 있게 했습니다.
