# FM27에서 이적을 결정하기 전에 확인한 것

렉섬을 운영하면서 이번 시즌은 지금 선수단으로 마치고 승격 뒤 개편하려 했습니다. 대체 선수를 구하기 어렵다면 다음 시즌 기준으로 24세 이하 선수는 남기기로 했습니다. 누구를 데려올지 정하려면 선수의 계약과 급료부터 봐야 했고 실제 이적 예산도 필요했습니다.

## 게임에서 실행한 버전과 수정 후보

**0.2.1을 게임과 함께 실행**했을 때는 구단 이름을 읽었고 선수 목록을 요청했을 때 응답도 왔습니다. 감독과 팀을 구분하는 값과 선수별 상세 ID를 확인하지 못해 도구는 수집을 중단했습니다. 계약이나 이적 예산까지 읽힌 상태였는지도 확인할 수 없었습니다.

**0.2.2 수정 후보**에서는 어떤 응답을 받아들일지 정하는 조건을 바꿨습니다. 오프라인에서 빌드한 뒤 데이터 형식을 확인하는 C# 검사 36개와 Python 검사 17개가 통과했습니다. 이 버전으로 게임을 다시 읽고 화면과 비교한 결과는 아직 없습니다.

그래서 선수단에서 보강할 포지션까지 먼저 정리했습니다. 구체적인 거래는 이적 예산과 급료를 확인한 뒤 판단하기로 했습니다.
