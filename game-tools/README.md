# 게임을 하면서 만든 도구와 검증 사례

지금 가진 장비 중 무엇을 바꿀지 궁금했고 사냥터를 옮겨도 지금 쓰는 도술이 좋은지 알고 싶었습니다. 그래서 게임에서 하던 고민을 직접 비교해 볼 수 있는 도구를 만들었습니다.

- [**Star Rail Lab**](star-rail-lab/README.md)으로 이미 가진 장비 중 무엇을 바꿀지 비교했습니다. 브라우저에서 조건을 바꿨을 때 이전 계산 결과가 사라지는지도 확인했습니다.
- [**깨비 덱 연구실**](kkaebi-deck-lab/README.md)에서 능력치나 사냥터를 바꾸고 충전 도술을 넣었을 때와 뺐을 때를 비교했습니다. 플레이 영상에서 확인한 것과 도구가 계산한 값도 볼 수 있습니다.
- [**와우 포에버 육성 안내**](wow-leveling-route.md)에는 먼저 챙길 직업 퀘스트와 나중에 갈 수 있는 던전을 나눠 담았습니다. 클래식의 퀘스트 순서를 포에버에 적용할 수 있는지도 다시 살폈습니다.
- [**FM27 선수단 분석**](fm27-data-readiness.md)은 승격 뒤 선수단을 어떻게 꾸릴지 검토한 사례입니다. 이적 예산이 제대로 읽히는지부터 확인했습니다.
