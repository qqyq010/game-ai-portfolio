# 게임을 하면서 만든 도구와 검증 사례

플레이 중 궁금했던 선택을 도구에서 비교할 수 있게 정리했습니다. 각 글에서 제가 정한 조건과 실제로 확인할 수 있는 범위를 볼 수 있습니다.

- **[Star Rail Lab](star-rail-lab/README.md)** · 이미 가진 장비로 뭘 바꿀지 고민하며 만든 비교 도구입니다. 입력을 바꾼 뒤 이전 결과가 지워지는지 브라우저와 로컬 API에서 확인했습니다.
- **[깨비 덱 연구실](kkaebi-deck-lab/README.md)** · 능력치와 사냥터를 바꾸고 충전 도술을 넣거나 뺀 조합을 비교합니다. 영상에서 본 규칙과 모델 검사 범위가 있습니다.
- **[와우 포에버 육성 안내](wow-leveling-route.md)** · 필드 퀘스트와 직업 해금, 선택할 던전을 나눴습니다. 클래식 동선을 그대로 가져왔을 때의 문제도 다시 봤습니다.
- **[FM27 선수단 분석](fm27-data-readiness.md)** · 승격 후 편성을 구상하면서 읽지 못한 예산과 선수 자료가 거래 판단에 쓰이지 않게 한 사례입니다.
