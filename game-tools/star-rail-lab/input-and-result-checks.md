# 조건을 바꾸면 이전 결과는 어떻게 될까

장비 선택을 바꿨는데 이전 계산이 계속 화면에 남아 있으면 지금 조건에 맞는 수치처럼 보입니다. 버튼을 빠르게 다시 누르면 이전 요청의 답이 늦게 돌아올 수도 있습니다. 그래서 보유 정보와 파티·콘텐츠 조건을 나눠 적고, 값이 바뀌는 순간 화면에서 일어나야 할 일을 정리했습니다.

| 입력 상황 | 확인할 동작 |
| --- | --- |
| 장비나 전투 길이를 바꿈 | 화면에서 이전 결과를 비우고 새 입력을 기준으로 다시 계산 |
| 이전 요청이 뒤늦게 끝남 | 현재 결과가 이전 응답으로 바뀌지 않음 |
| 계산에 쓰는 자료를 읽음 | 원하는 자료의 식별값인지 확인 |

지금 공개한 사례는 지정 파티의 한 캐릭터 장비 비교입니다. [코드 발췌](code/rotation-input-excerpt.jsx)에 입력 변경과 응답 구분이 있습니다. 화면 피해량은 모델 계산값이고, 실제 게임 측정으로 대조하는 일과 보유 자원 기반의 여러 파티 비교는 추가 작업으로 남았습니다.
