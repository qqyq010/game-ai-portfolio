# 조건을 바꾸면 이전 결과는 어떻게 될까

장비를 바꿨는데 전에 계산한 표가 그대로 남으면 새 장비의 수치로 오해하기 쉽습니다. 버튼을 연달아 눌렀을 때 이전 요청이 더 늦게 끝날 수도 있습니다. 그래서 어떤 콘텐츠를 플레이하는지와 그때 쓸 장비와 파티를 각각 입력하게 했습니다. 입력을 바꾼 뒤 화면에서 어떻게 보여야 하는지도 정했습니다.

| 상황 | 기대한 동작 |
| --- | --- |
| 장비나 전투 길이를 바꿈 | 이전 결과를 지우고 바뀐 조건으로 다시 계산 |
| 이전 요청이 더 늦게 끝남 | 새 결과를 이전 결과로 덮어쓰지 않음 |
| 계산에 쓰는 자료를 불러옴 | 사용하려는 자료와 식별값이 같은지 확인 |

[코드 발췌](code/rotation-input-excerpt.jsx)에서 입력과 응답을 구분하는 부분을 볼 수 있습니다. 예시에서는 정해진 파티 안에서 캐릭터 한 명의 장비를 비교했습니다. 화면의 피해량은 도구가 계산한 값입니다. 실제 게임에서 피해량이 어떻게 나오는지와 제가 가진 캐릭터로 짠 다른 파티도 비교할 수 있는지는 추가로 확인해야 합니다.
