# Coin Survivor

팀 게임 프로젝트에서 상점과 인벤토리를 다루며 확인한 두 사례입니다.

## 판매한 무기가 전투에 남는 문제

판매한 무기가 가방에서는 사라졌지만 전투에서 계속 공격했습니다. 같은 종류라도 레벨이 다른 무기가 남아 있어야 했기 때문에, 판매한 2레벨 무기만 제거되고 1레벨 무기는 유지되는 조건을 정했습니다.

| 역할 | 작업 |
| --- | --- |
| 본인 | 재현 증상과 확인 조건을 정하고, 수정 대상을 인벤토리 쪽으로 제한한 뒤 Play Mode 결과를 확인했습니다. |
| Codex | 인벤토리 쪽 판매 이벤트 처리 코드를 수정하고 빌드를 수행했습니다. |
| 팀원 | 전투에서 제거 이벤트를 받는 Player 측 코드를 구현했습니다. |

### 재현과 확인 조건

1. 동일 종류의 1레벨·2레벨 무기가 있는 상태에서 2레벨 무기를 판매합니다.
2. 판매한 무기가 전투에서 더 이상 공격하지 않는지 확인합니다.
3. 판매하지 않은 1레벨 무기는 계속 전투에 남는지 확인합니다.

| 확인 항목 | 기대 동작 | 당시 기록 |
| --- | --- | --- |
| 판매한 2레벨 무기 | 해당 무기만 전투에서 제거 | Play Mode에서 확인 |
| 판매하지 않은 1레벨 무기 | 동일 종류여도 전투에서 유지 | Play Mode에서 확인 |
| 방어구 구매·판매 | 해당 자산을 사용해 별도 확인 | 적합한 재현 자산이 없어 미확인 |

빌드 성공과 Play Mode 결과를 따로 기록했습니다. Play Mode 결과는 당시 제가 직접 확인해 남긴 기록이며, 독립 녹화나 콘솔 로그는 확보하지 못했습니다.

## 초반 골드로 어떤 선택이 가능한가

초반 골드를 가방 확장에 쓰면 아이템 구매를 포기하게 되고, 이후 전투가 어려워진다고 판단했습니다. 골드가 성장에도 쓰이는 구조라 상점 입장 비용을 전부 없애는 대신, 초반 확장 비용은 낮추고 후반으로 갈수록 높이는 방향을 제안했습니다.

| 비교 항목 | 다음 플레이에서 확인할 질문 |
| --- | --- |
| 웨이브별 골드 수급 | 구매를 고민하는 시점까지 얼마나 벌 수 있는가? |
| 가방 확장비와 상점 지출 | 확장하고도 아이템을 살 여유가 있는가? |
| 다음 전투에서의 처치 난이도 | 구매 여력이 달라졌을 때 어디서 전투가 막히는가? |

위 표는 비교할 항목을 설명합니다. 최종 적용 버전과 반복 플레이에서의 개선 효과는 미확인입니다.
