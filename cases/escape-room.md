# EscapeRoom

Unity로 만든 개인 잠입 퍼즐 프로젝트입니다. 공간을 탐색하다 적에게 감지되거나 퍼즐에 실패하면, 입력을 잠그고 실패 상황을 알린 뒤 다시 조작할 수 있도록 복구합니다.

지금 이동·퍼즐 조작을 허용할지를 결정하는 상태와 이미 해결한 퍼즐의 진행 상태를 분리했습니다. 감지에는 거리와 시야각, 장애물 확인을 사용했습니다.

2026년 8월 24일 임시 복사본의 자동 Play Mode 검사에서 SceneA 로드와 초기화, 입력 잠금과 해제, 대표 퍼즐 실패 이후의 정상 상태 복귀를 확인했습니다. 1건 통과 기록이며 전체 퍼즐 수동 완주 또는 배포용 빌드 실행은 별도입니다.
