# Fisher Idle RPG

팀 프로젝트에서 상점·요리·가방·도감 화면의 클라이언트 UI와 외부 요청 연결을 다뤘습니다.

버튼을 누른 뒤 응답을 기다리는 사이, 같은 버튼을 다시 누르거나 다른 항목을 선택하거나 화면을 닫을 수 있습니다. 화면 선택, 요청 상태, 돌아온 데이터의 책임을 다음과 같이 나눴습니다.

| 구간 | 확인할 책임 |
| --- | --- |
| Panel Adapter | 화면의 현재 선택, 버튼 상태, 안내와 결과 표시 |
| Request Gate | 요청 중 재입력, 현재 요청의 식별값, 응답 대기 시간 |
| Data Bridge | 요청 전달, 응답을 받고 클라이언트 상태에 적용 |

구현 기록은 이 클라이언트 흐름을 설명합니다. 서버 함수 전체와 라이브 서버 검증은 이 사례의 범위에 포함되지 않습니다.
