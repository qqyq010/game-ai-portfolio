# 플레이하면서 눈여겨본 것

초등학생 때부터 여러 장르의 게임을 즐겼습니다. 와우에서는 오래 걷는 길도 탐험의 일부였습니다. Football Manager에서는 선수단을 꾸리고 나서 시즌이 어떻게 끝날지 기다리는 재미가 있었습니다. 문명과 XCOM은 한 번의 선택 때문에 이후 전개가 달라지는 점이 좋았습니다. Steam 창작마당의 모드로 익숙한 게임도 다르게 느낄 수 있다는 걸 보고 저도 규칙을 바꿔 보고 싶었습니다.

## 오래 플레이한 게임

| 게임 | 플레이 시간과 해 본 일 |
| --- | --- |
| Football Manager 2023 | 420.7시간. 월드컵 우승 기록 |
| 문명 5 | 58.6시간. 모든 승리 조건 달성 기록 |
| 스타크래프트 2 | 캠페인과 노바 임무를 완료 |
| 월드 오브 워크래프트 | 기록을 볼 수 있는 캐릭터만 합쳐 2,158시간. 정예 타락자 느조스 업적 달성 |
| 던전앤파이터 | 여러 직업을 키웠습니다. 당시 모험단 43레벨에 캐릭터 59개가 있었습니다. |
| 리그 오브 레전드 | 오랫동안 플레이한 온라인 팀 대전 게임 |
| 붕괴 스타레일 | 활동 308일에 업적 1,091개를 기록했습니다. 제가 가진 장비끼리 비교해 보고 싶어서 [Star Rail Lab](../game-tools/star-rail-lab/README.md)을 만들었습니다. |
| PUBG | 124.8시간 |
| Slay the Spire | 94.9시간. 아이언클래드 클리어 기록 |

## Steam 라이브러리

2026년 10월 초에는 Steam 라이브러리에 게임이 427개 있었습니다. 11월에 지원서를 쓸 때는 392개가 표시됐습니다.

9월 22일에 플레이 시간이 표시된 게임은 162개였습니다. [게임별 플레이 시간](steam-playtime.md)
