# 플레이하면서 눈여겨본 것

초등학생 때부터 여러 장르를 즐겼습니다. 와우에서는 오래 걸리는 길도 탐험의 일부였고, Football Manager에서는 선수단을 꾸리며 한 시즌 뒤의 결과를 기다리는 재미가 있었습니다. 문명과 XCOM에서는 한 번의 선택이 이후의 플레이를 바꿨습니다. 창작마당의 모드가 익숙한 게임의 규칙을 바꾸는 걸 보면서 직접 만들어 보고 싶어졌습니다.

## 오래 플레이한 게임

| 게임 | 당시 확인한 기록 또는 플레이 경험 |
| --- | --- |
| Football Manager 2023 | 420.7시간. 월드컵 우승 기록 |
| 문명 5 | 58.6시간. 모든 승리 조건 달성 기록 |
| 스타크래프트 2 | 캠페인과 노바 임무 완료 기록 |
| 월드 오브 워크래프트 | 확인한 캐릭터의 시간 합계 2,158시간. 정예 타락자 느조스 업적 |
| 던전앤파이터 | 여러 직업을 키웠고, 당시 모험단 43레벨·캐릭터 59개 기록 |
| 리그 오브 레전드 | 오래 즐긴 온라인 팀 대전 게임 |
| 붕괴 스타레일 | 활동 308일·업적 1,091개 기록. 보유 장비 비교에 대한 관심이 [Star Rail Lab](../game-tools/star-rail-lab/README.md)으로 이어졌습니다. |
| PUBG | 124.8시간 |
| Slay the Spire | 94.9시간. 아이언클래드 클리어 기록 |

## Steam 기록의 시점

| 수치 | 무엇을 센 기록인가 |
| --- | --- |
| **392개** | 2026년 11월 지원 당시 Steam 라이브러리 표시에 남은 수 |
| **427개** | 2026년 10월 초의 보유 기록. [이전 포트폴리오 PDF](../portfolio.pdf)에도 이 수치가 쓰였습니다. |
| **162개** | 2026년 9월 22일에 플레이 시간이 표시된 항목 수. [게임별 당시 표시 시간](steam-playtime.md) |

온라인 게임은 게임 안에서 확인한 캐릭터·업적 기록과 플레이 경험이 있습니다. 위의 시간은 각 자료에서 확인한 범위의 값입니다.
